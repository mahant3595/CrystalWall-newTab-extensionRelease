    Zen view

    The eye button in the corner clears the page down to what you keep below. Escape or the eye brings everything back.

    The wallpaper always stays — it is the scene, not a widget. Every floating widget you switch on (the weather card, and each photo or video widget you add) gets its own row here. The eye always remains so you can leave Zen view.

    About Crystal Wall

    What this extension is, where its website lives, and what the license allows.

    Version 1.3.0

    The new tab this installs

    Crystal Wall replaces the new tab with your own wallpaper and a set of widgets you arrange yourself: a glass clock and date, search with suggestions, weather, a focus timer, quotes, quick links and a notes pad. Fourteen themes, live and animated wallpapers, widget stacking, Zen view, a command palette and keyboard shortcuts are included.

    Everything you add — wallpapers, photos, music, themes, notes, shortcuts — stays in this browser's own storage. There is no account and no server of ours. Settings → Backup moves the whole setup to another profile in one file, so nothing is lost when you reinstall.

    Website

    The feature tour, the install steps for Chrome, Edge and the other Chromium browsers, and the list of recent changes are on the project site. Keep this address: if you ever lose this page, or want Crystal Wall on a second computer, this is where it comes from.
